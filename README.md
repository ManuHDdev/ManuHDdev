## 🚀 Proyectos Destacados

### 🏪 [Sistema WMS - Chanel España](https://github.com/ManuHDdev)
Sistema integral de gestión de inventario empresarial con arquitectura de microservicios. Actualmente en producción gestionando toda la logística de Chanel en España.

**Características:**
- 12 microservicios independientes
- Autenticación empresarial con Keycloak (OAuth2 + OpenID Connect)
- +120 funcionalidades implementadas
- Importación/exportación masiva de datos
- Sistema de roles y permisos granulares
- Generación automática de documentos (PDFs, etiquetas)
- Backups automatizados con Google Drive

**Tech Stack:** `Angular 16` `Spring Boot 17` `Keycloak` `MySQL` `PostgreSQL` `Docker` `Nginx`
